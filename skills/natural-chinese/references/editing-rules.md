# 中文表达规则与适用边界

第一原则：调后不改变原文的意思。

## 一、多余的义肢：删除不承担意义的外壳

### 1. 当……的时候

- “当他看见我回来的时候，他就向我奔来。” -> “看见我回来，他就向我奔来。”

### 2. 在……方面／上／期间

- “在鞋的品质方面” -> “鞋的品质”
- “在上午上课期间” -> “上午上课期间”

### 3. 多余的“地”

- “不知不觉地就看完了” -> “不知不觉就看完了”
- “他愤然地走开” -> “他愤然走开”

### 4. 多余的“着”

- “靠着打鱼生活” -> “靠打鱼生活”
- “有着很大的脾气” -> “脾气很大”

### 5. 多余的“所”

- “我所能想到的办法，都失败了。” -> “我能想到的办法，都失败了。”

### 6. 多余或单调的“们”

数量和群体已经明确时，可以省去“们”。

- “先生们” -> “各位先生”（适合正式称呼）
- “医生们一致认为他已经康复了” -> “医生一致认为他已经康复了”
- 泛指一批对象时，可考虑“这批强盗”“这些学生”“各地选手”。

### 7. 多余的“有关／关于”

- “我今天上午听到一个有关联合国的消息” -> “我今天上午听到一个联合国的消息”（仅限“谈论联合国”与“来自联合国”不会混淆的上下文）

“关于”能区别内容主题与所有者、发布者或对象。删掉会产生歧义时保留。

### 8. 多余的“作为”

身份说明拖慢句子时，可以换成“身为”或直接写出身份与责任。

- “作为一个中国人，我们怎能不爱中国？” -> “身为中国人，怎能不爱中国？”

“作为”表达用途、资格或角色时保留，如“作为证据提交”。

### 9. 多余的“作出”

- “对于这件事，你们还没有作出决定吗？” -> “这件事你们还没有决定吗？”
- “兄弟两个争论了一夜，最后还是哥哥作出让步。” -> “兄弟两个争论了一夜，最后还是哥哥让步。”

### 10. 多余的“存在”

- “台北市的交通有不少问题存在” -> “台北市的交通有不少问题”

## 二、滥用：恢复具体的关系和指代

### 11. 过多的“的”

- “我发现了一束开得正艳丽的黄色的连翘花在书桌上，旁边还有一片写着你亲切的语句的白纸。” -> “我发现书桌上有一束黄色连翘花，开得正艳丽；旁边还有一片白纸，写着你亲切的话。”

### 12. 过多的“和”

先辨明并列、递进、转折或先后关系，再选择连接方式。

- “李太太的父亲年老和常生病” -> “李太太的父亲年老多病”
- “同事们都认为他的设计昂贵和不切实际” -> “同事都认为他的设计昂贵而不切实际”

可以按关系考虑“并”“并且”“及”“以及”“与”“且”“而”“而且”，也可以省去连接词。

### 13. 过多的“通过”

- “通过反复交涉，双方终于达成一致” -> “经过反复交涉，双方终于达成一致”（突出过程）
- “通过步行的方式到校” -> “步行到校”

### 14. 代词滥用

主语连续且唯一时，可以省去重复的“它”“它们”“我们”等代词。

- “花莲是台湾东部的小城，它以海景壮美闻名。” -> “花莲是台湾东部的小城，以海景壮美闻名。”

指代不明时直接重复名词；需要回指时可用“这”“这些”“那”“那些”。

### 15. 滥用“一个”

“一个”没有计数、强调或引入新对象的作用时，可以试删。

- “这是一个值得讨论的问题。” -> “这个问题值得讨论。”

### 16. 泛用“证明／显示／表明”和“足够”

- “他有足够的钱养家糊口。” -> “他的钱够养家糊口。”

## 三、精确与直译：保留有效限定

### 17. “……之一”与“最……之一”

- “李广是汉朝名将之一” -> “李广是汉朝名将”
- “《红楼梦》是中国的文学名著之一” -> “《红楼梦》是中国的文学名著”

## 四、抽象词：让词语承担实际内容

专有名词、常用词时保留。

### 19. “XX 性”

- “这本书可读性很高” -> “这本书很好读／很有趣／很耐看”（根据实际含义选择）
- “专业性很强” -> “很专业”（普通评价中）

### 20. “XX 度”

- “具有很高的知名度。” -> “很有名。”

### 21. “XX 主义”

- “陆游的作品里存在着极高度的爱国主义精神。” -> “陆游的作品富于爱国精神。”

### 22. “XX 者”

- “他是一位长期的素食主义的奉行者。” -> “他长期吃素。”

## 五、句式：让动作和对象尽早出现

### 23. 前置修饰太长

先交代对象，再展开外貌、行为或条件。

- “我见到一个长得像你兄弟说话也有点像他的陌生男人。” -> “我见到一个陌生男人，长得像你兄弟，说话也有点像他。”

### 24. 把动作压成名词，再拿来作主语或宾语

- “他的不肯就范让谈判陷入僵局。” -> “他不肯就范，谈判因此陷入僵局。”

### 25. 用抽象动词加名词代替直接的动作

留意“进行”“接受”“作出”“从事”“进入……状态”等外壳，让具体动词作谓语。

- “做这次旅行” -> “去旅行／这次旅行”
- “作了一次私下谈话” -> “私下谈了一次”
- “作了五年的奋斗” -> “奋斗了五年”
- “进行了为期三日的研究” -> “研究了三天”
- “做些什么商谈” -> “商谈些什么”
- “得到更大的安全” -> “更安全／得到更多保护”（按实际含义选择）
- “进入睡眠状态” -> “入睡”
- “从事一次航行” -> “航行一次／出航”（按语境选择）

### 26. 被动句

若无必要，避免使用被动句式。

- “他被吓得昏过去了” -> “他吓得昏过去了”
- “钟被敲了三下” -> “钟敲了三下”
- “房间已经被布置好了” -> “房间已经布置好了”

按文体和遭遇可考虑“受”“遭”“挨”“给”“叫”“教”“让”或“为……所……”等结构。
