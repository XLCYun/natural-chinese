# 中文表达规则与适用边界

这些规则把用户提供的中文写作材料整理成表达指南，适用于日常回答、技术说明、进度回复、写作和修改。关于英语词形、介词或句式的联想，只用于识别可能的翻译腔，不据此断言某个中文词的历史来源或语法地位。

生成中文时直接选用符合语境的自然说法；修改已有文本时，把示例当作可选改法。是否采用，要看上下文中的含义、指代和节奏；篇幅更短本身不是表达更好的依据。

## 一、多余的义肢：删除不承担意义的外壳

### 1. 当……的时候

事件的先后或触发关系已经清楚时，可以直接叙述动作。

> 当他看见我回来的时候，他就向我奔来。
>
> → 看见我回来，他就向我奔来。

表达严格条件、时间区间或对照关系时保留，如“当温度低于零度时，启动加热”。省略后若主语不清，也应补明。

### 2. 在……方面／上／期间

去掉只把话题包起来的介词结构，让对象直接进入句子。

- “在鞋的品质方面” → “鞋的品质”。
- “在上午上课期间” → “上午上课期间”。

例子是片段，放回整句后再定稿。“在桌上”表示地点，“在质量上领先、在价格上落后”建立对比，都有实际作用。

### 3. 多余的“地”

副词与动词本来衔接自然时，试删“地”，尤其留意“不知不觉地”和“愤然地”等表达。

- “不知不觉地就看完了” → “不知不觉就看完了”。
- “他愤然地走开” → “他愤然走开”。

不按“X然地”一律删除。修饰关系、强调、朗读节奏需要“地”时保留；也不靠批量删字解决“的／地／得”的误用。

### 4. 多余的“着”

- “靠着打鱼生活” → “靠打鱼生活”。
- “有着很大的脾气” → “脾气很大”。

“着”表达持续状态或伴随动作时保留，如“门开着”“他笑着说”。判断句子表达的状态，不能把所有“着”都当成进行时的赘字。

### 5. 多余的“所”

普通叙述中可以试删不影响意思的“所”。

> 我所能想到的办法，都失败了。
>
> → 我能想到的办法，都失败了。

固定表达、正式行文或强调范围时可以保留，如“各有所长”“如前所述”。

### 6. 多余或单调的“们”

数量和群体已经明确时，可以省去“们”，也可以按语境使用“各位”“众人”“这批”“这些”“各地”等表达。

- “先生们” → “各位先生”（适合正式称呼）。
- “医生们一致认为他已经康复了” → “医生一致认为他已经康复了”。
- 泛指一批对象时，可考虑“这批强盗”“这些学生”“各地选手”。

“都”“一致”提示检查复数标记是否重复，并不使“们”自动成为语病。数量词、指示词和“各地”会改变范围，只能在上下文支持时使用。“人们”可以泛指社会中的人，“大家”常指当前群体，“人人”强调每个人，三者不能随意互换。保留自然的“我们”“孩子们”等表达。

### 7. 多余的“有关／关于”

- “你有关于他的资料吗？” → “你有他的资料吗？”
- “我今天上午听到一个有关联合国的消息” → “我今天上午听到一个联合国的消息”，仅限“谈论联合国”与“来自联合国”不会混淆的上下文。

“关于”能区别内容主题与所有者、发布者或对象。删掉会产生歧义时保留，如“关于他的报道”与“他的报道”未必同义。标题或句首用来界定议题时也可以保留。

### 8. 多余的“作为”

身份说明拖慢句子时，可以换成“身为”或直接写出身份与责任。

> 作为一个中国人，我们怎能不爱中国？
>
> → 身为中国人，怎能不爱中国？

“作为”表达用途、资格或角色时保留，如“作为证据提交”。“身为”也有语体色彩，不需要把每个“作为”都换成“身为”。

### 9. 多余的“作出”

让后面的动作直接作谓语。

- “对于这件事，你们还没有作出决定吗？” → “这件事你们还没有决定吗？”
- “兄弟两个争论了一夜，最后还是哥哥作出让步。” → “兄弟两个争论了一夜，最后还是哥哥让步。”

“作出判决”等正式行为名称、需要突出结果或与后文衔接的结构，可以保留。

### 10. 多余的“存在”

> 台北市的交通有不少问题存在。
>
> → 台北市的交通有不少问题。

重点删掉“有……存在”的重复。谈论是否真实存在、存续状态或专门概念时保留，如“这种风险仍然存在”。

## 二、滥用：恢复具体的关系和指代

### 11. 过多的“的”

连续修饰遮住了中心词时，把人物、对象和动作提到前面，或拆成两句。

> 我发现了一束开得正艳丽的黄色的连翘花在书桌上，旁边还有一片写着你亲切的语句的白纸。
>
> → 我发现书桌上有一束黄色连翘花，开得正艳丽；旁边还有一片白纸，写着你亲切的话。

保留所属关系和必要的修饰关系，如“我的书”。目标是让修饰层次清楚，不是限制一个句子中“的”的数量。

### 12. 过多的“和”

先辨明并列、递进、转折或先后关系，再选择连接方式。

- “李太太的父亲年老和常生病” → “李太太的父亲年老多病”。
- “同事们都认为他的设计昂贵和不切实际” → “同事都认为他的设计昂贵而不切实际”。

可以按关系考虑“并”“并且”“及”“以及”“与”“且”“而”“而且”，也可以省去连接词。它们的语体和逻辑不同，不能为了避开“和”轮流替换；名词并列中的“和”通常很自然。

### 13. 过多的“通过”

按句意区分手段与过程。

- “通过反复交涉，双方终于达成一致” → “经过反复交涉，双方终于达成一致”（突出过程）。
- “通过步行的方式到校” → “步行到校”。

确实强调途径或手段时保留，如“通过公开接口查询”。“通过考试”中的“通过”也不是这种介词外壳。

### 14. 代词滥用

主语连续且唯一时，可以省去重复的“它”“它们”“我们”等代词。

> 花莲是台湾东部的小城，它以海景壮美闻名。
>
> → 花莲是台湾东部的小城，以海景壮美闻名。

指代不明时直接重复名词；需要回指时可用“这”“这些”“那”“那些”，但要检查距离和所指范围。涉及多个行动者、主语切换或刻意对比时，保留必要的代词。句首“我们”若承担作者立场或邀请读者的作用，也应保留。

### 15. 滥用“一个”

“一个”没有计数、强调或引入新对象的作用时，可以试删。

> 这是一个值得讨论的问题。
>
> → 这个问题值得讨论。

“我只有一个问题”“门口站着一个陌生人”中的“一个”承担数量或叙事功能，应按原意保留。

### 16. 泛用“证明／显示／表明”和“足够”

直接陈述已经有依据的事实，不为每句话套上“这证明了／这显示了”。如果这些词标记证据与结论的关系，就保留，并维持原来的证据强度；不能把“表明”一概升级成“证明”。

“足够”可以在日常语境中换成更自然的“够”。

> 他有足够的钱养家糊口。
>
> → 他的钱够养家糊口。

谈论阈值、标准或正式条件时保留，如“需要足够的证据”。不要随手补“了”，以免添加原文没有的状态变化。

## 三、精确与直译：保留有效限定

### 17. “……之一”与“最……之一”

只是表达身份或类别，删掉“之一”仍不暗示唯一时，可以直接说。

- “李广是汉朝名将之一” → “李广是汉朝名将”。
- “《红楼梦》是中国的文学名著之一” → “《红楼梦》是中国的文学名著”。

“最伟大的诗人之一”不能直接改成“最伟大的诗人”。若语境只是在称赞，可考虑“极伟大的诗人”或“大诗人”，同时核对评价力度是否仍符合原意；若排名、集合成员或非唯一性关系重要，保留原有限定。“三个试点之一”“最早的记录之一”通常承担实质信息。

### 18. 一字一译

寻找中文里已经自然使用的词，而不是照外语词序逐词拼装。

> family member → 日常语境可译作“家人”，不必总写“家庭的一员”或“家庭成员”。

法律、统计或其他专门语境中的“家庭成员”可能有明确定义，应保留。以含义、语域和既有译名为准。

## 四、抽象词：让词语承担实际内容

### 19. “XX 性”

- “这本书可读性很高” → 根据实际含义改成“这本书很好读”“很有趣”或“很耐看”。
- “专业性很强” → 普通评价中可改成“很专业”。

“好读”“有趣”“耐看”评价的维度不同，不能随意代换。“专业性强”有时表示门槛高，而“很专业”可能赞扬水准，须由上下文定夺。安全性、可靠性、线性等概念应保留。

### 20. “XX 度”

> 具有很高的知名度。
>
> → 很有名。

测量指标、调查维度和专门概念需要保留，如“温度”“能见度”“用户满意度”。讨论调查结果时，“知名度”也可能比“有名”准确。

### 21. “XX 主义”

> 陆游的作品里存在着极高度的爱国主义精神。
>
> → 陆游的作品富于爱国精神。

只在抽象套语遮住具体意思时换写。表示明确思想体系、流派或政治概念的名称，如“现实主义”“社会主义”，保留原词及其立场。

### 22. “XX 者”

> 他是一位长期的素食主义的奉行者。
>
> → 他长期吃素。

只有原句意在说明饮食习惯时才这样改；如果强调信念、身份或组织归属，要保留那层意思。自然的身份名称，如“作者”“读者”“研究者”，不需要刻意改写。

## 五、句式：让动作和对象尽早出现

### 23. 前置修饰太长

先交代对象，再展开外貌、行为或条件。

> 我见到一个长得像你兄弟说话也有点像他的陌生男人。
>
> → 我见到一个陌生男人，长得像你兄弟，说话也有点像他。

如果长修饰用于区分多个候选对象，拆句后仍要让读者知道说的是哪一个。

### 24. 把动作压成名词，再拿来作主语或宾语

把“他的不肯就范”“他的将计就计”等结构还原成发生的事，让动作有主体。

> 他的不肯就范让谈判陷入僵局。
>
> → 他不肯就范，谈判因此陷入僵局。

“我不喜欢他的‘将计就计’”若指做法，可以写“我不喜欢他将计就计的做法”；若讨论的就是这条策略或这个词，则保留引用。“游泳有益健康”这类自然的动作主语无需改写。

### 25. 用抽象动词加名词代替直接的动作

留意“进行”“接受”“作出”“从事”“进入……状态”等外壳，让具体动词作谓语。

| 原表达 | 可选改法 |
| --- | --- |
| 做这次旅行 | 去旅行／这次旅行，按句法选择 |
| 作了一次私下谈话 | 私下谈了一次 |
| 作了五年的奋斗 | 奋斗了五年 |
| 进行了为期三日的研究 | 研究了三天 |
| 做些什么商谈 | 商谈些什么 |
| 得到更大的安全 | 更安全／得到更多保护，按实际含义选择 |
| 进入睡眠状态 | 入睡 |
| 从事一次航行 | 航行一次／出航，按语境选择 |

保留动作是否完成、次数、时长和对象；“出航”只突出启程，不一定能代替整次航行。正式流程名、术语及无法直接动词化的搭配，如“接受治疗”，按语境保留。

### 26. 被动句

先判断叙述重点，再决定语态。施事者明确且重要时，可让施事者作主语；受事者才是话题、施事者未知或无需说明时，被动句可以很自然。

- “他被许可来美” → “他已获准赴美”（以叙述地点允许“来”改成“赴”为前提）。
- 只有材料已经明确批准方时，才可写“美国批准他赴美”等主动句，不能猜出一个行为者。
- “他被吓得昏过去了” → “他吓得昏过去了”。
- “钟被敲了三下” → “钟敲了三下”。
- “房间已经被布置好了” → “房间已经布置好了”。

按文体和遭遇可考虑“受”“遭”“挨”“给”“叫”“教”“让”或“为……所……”等结构。“遭”“挨”通常带有不利意味，“给”“叫”“让”更口语，“为……所……”偏书面，不能作为“被”的通用同义词。古语中的“见”也不是现代文章应当常用的替代项。

“他被公司解雇了”“数据被误删了”等句子中，受事者及其遭遇就是重点，可以保留。避免为了省一个“被”字，弄丢施事者、责任归属或事件本身。
